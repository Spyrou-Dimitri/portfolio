# 🎱 Portfolio – Thème Billard

## 1. Description

Ce portfolio est un projet que j’ai réalisé dans le cadre de ma deuxième année de bachelier. J’ai souhaité y intégrer ma passion pour le billard en concevant une interface unique, immersive et élégante, à l’image de cet univers qui me tient à cœur.

---

## 2. Fonctionnalités principales 🌟

- Présentation de mes **projets**, **expériences** et **compétences**
- Sections :
    - 🏠 Accueil
    - 👤 À propos
    - 🛠️ Projets
    - 📬 Contact via formulaire (PHP)
- 🎨 Intégration de **Fancybox** pour afficher les visuels en lightbox
- 🟢 Thème graphique inspiré du **billard** : tables, boules, ambiance feutrée

---

## 3. Technologies utilisées 🛠️

- **HTML5** – Structure sémantique du site
- **SASS** – Préprocesseur CSS pour des styles organisés et modulaires
- **JavaScript** – Interactions et effets dynamiques
- **PHP** – Traitement du formulaire de contact
- **WordPress** – CMS pour la gestion du contenu
- **Fancybox** – Plugin jQuery pour les galeries d’images
